## 🚀 三步跑起来（小白版，逐字照抄即可）

### 第 1 步：打开终端

- **macOS**：打开「启动台」→ 搜索 `终端`(Terminal)
- **Windows**：菜单搜 `PowerShell` 或 `Terminal`
- **Linux**：Ctrl+Alt+T

把下面命令**一行一行**复制粘贴进去按回车（# 开头的是注释，不用复制）：

```bash
# 进入课程文件夹（把路径换成你实际放课程的地方）
cd /Users/jimmy/codes/NativeAI-Zero-to-Hero

# 看一眼里面是不是有 L01...L40 这些文件
ls
```

### 第 2 步：建一个"沙盒"并装工具（只做一次）

```bash
# 建虚拟环境（会生成一个 .venv 文件夹，这就是沙盒）
python3 -m venv .venv

#  activate 激活沙盒（mac/Linux 用下面这行）
source .venv/bin/activate
# 如果是 Windows PowerShell，用这行代替：
# .venv\Scripts\Activate.ps1

# 装课程需要的全部工具（都在沙盒里，不动系统）
pip install -r requirements.txt

# 装 Jupyter（用来打开那些 .ipynb 文件）
pip install jupyter
```

激活成功后，你的命令行最前面会多一个 `(.venv)` 字样，说明你已经在沙盒里了。✅

### 第 3 步：启动课程，开始玩

```bash
# 启动 Jupyter（会自动打开浏览器）
jupyter notebook
```

浏览器里点开 `L01_Python初见.ipynb`，从上往下依次点「▶ Run」(或按 Shift+Enter) 运行每个格子，跑完最后一格感受「哇！」瞬间。

## ❓ 常见问题（小白必看）

**Q：命令行里输入 `python3` 报 "command not found"？**  
A：说明你还没装 Python。去 https://www.python.org/downloads 下载安装（勾选 "Add to PATH"），再重开终端即可。

**Q：激活沙盒时提示"权限不足 / 无法加载文件"？**  
A（Windows）：PowerShell 默认禁止脚本，执行 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` 后重开终端。  
A（mac/Linux）：若报"无法执行"，先跑一次 `chmod +x .venv/bin/activate` 再 `source`。

**Q：有些课运行报错 "ModuleNotFoundError: No module named 'xxx'"？**  
A：你大概率**忘了激活沙盒**或**没装依赖**。确认命令行前面有 `(.venv)`，再跑一遍 `pip install -r requirements.txt`。

**Q：需要 GPU / 花钱买 API 吗？**  
A：**完全不需要**。前 30 课离线可跑；涉及大模型的课用纯代码演示原理并标注了"真 LLM 升级路径"，想深入再自行配 key，课程本身零成本。

**Q：跑出来的图/动画没显示？**  
A：确认是在 Jupyter 里点格子运行，而不是普通文本编辑器。浏览器里的 `.ipynb` 才是运行环境。
